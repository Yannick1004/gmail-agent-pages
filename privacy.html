Datenschutzerklärung – Gmail Agent

Stand: September 2026

1. Wer nutzt die Anwendung?

Gmail Agent ist ein privates Werkzeug, das nur vom Entwickler selbst für sein eigenes Gmail-Konto verwendet wird. Es gibt keine weiteren Nutzer.

2. Welche Daten werden verarbeitet?

Über die Gmail-API liest die Anwendung Absender, Betreff und einen kurzen Textauszug eingehender E-Mails. Auf dieser Grundlage setzt sie Labels, markiert Nachrichten als wichtig oder archiviert sie.

3. Weitergabe an Dritte

Zur Einordnung der E-Mails werden die genannten Auszüge an die API von Anthropic (Claude) übermittelt. Darüber hinaus werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt.

4. Speicherung

Die Anwendung läuft lokal auf dem Computer des Entwicklers. Es werden keine E-Mail-Inhalte dauerhaft gespeichert. Lokal gespeichert werden nur die Zugangsdaten (OAuth-Token), damit die Anwendung auf das eigene Postfach zugreifen kann.

5. Nutzung von Google-Daten

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

6. Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
